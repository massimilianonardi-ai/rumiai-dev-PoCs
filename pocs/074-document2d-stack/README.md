# Stack Document2D

Esperimento autonomo sulla composizione di proiezione con folding, celle grafema/TAB e annotazioni sovrapposte. Il backend è dimostrativo. Il caso usa un fold predefinito e terminatori LF.

Aprire `index.html` dal checkout in un browser moderno con `Intl.Segmenter`. I test in `tests/tests.js` vengono eseguiti al caricamento. La pagina mostra PASS quando tutte le asserzioni riescono.

Premere **Sostituisci con X** per modificare la B oltre il fold. Per provare il rifiuto delle coordinate scadute, premere **Ripristina**, **Apri / chiudi fold**, quindi **Sostituisci con X**.
