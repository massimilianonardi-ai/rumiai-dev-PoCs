RumiAI · PoC 063 · Prova interattiva

Modello reale PieceDocument + TextEditSelections, planner esterno a colonne e storico esterno. Funziona localmente nel browser, senza servizi cloud.

Selezioni e colonne

Aggiungi cursore
I cursori aggiuntivi sono visibili nell’elenco, non disegnati nella textarea. Un clic nel documento torna a un solo cursore.
Incolla rettangolare sperimentale
Il secondo pulsante attende un vero ⌘V/Ctrl+V nel documento. Le righe oltre EOF sono create solo verso il basso. Rettangolo impostato tramite campi, non col mouse.

Selezioni del modello


 
Limiti deliberati: demo fino a 256 KiB, documento interamente specchiato nella textarea. Non è un test di rendering per file giganti né un editor pronto per l’uso quotidiano. L’undo è solo in memoria; salva esplicitamente il lavoro.
